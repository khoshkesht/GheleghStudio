# Ghelegh Studio

وب‌سایت استاتیک و RTL قلق استدیو؛ بدون فریم‌ورک و با HTML، CSS و JavaScript سبک.

## اجرا

فایل `index.html` را در مرورگر باز کنید یا با هر static server ساده اجرا کنید.

## نگهداری

- رنگ‌های برند در متغیرهای `:root` در `assets/css/main.css` هستند.
- اطلاعات تماس موقت در `contact.html` با کامنت TODO مشخص شده است.
- برای افزودن بازی، یک `article.game-card` در `games.html` اضافه کنید؛ تصاویر در `assets/images/games/` قرار می‌گیرند.
- تصاویر رَدینو در `assets/images/radino/` قرار دارند.
